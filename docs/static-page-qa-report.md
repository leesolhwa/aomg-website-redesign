### 검수 환경 제약
- 샌드박스에서 Google Fonts·jsDelivr 접속이 막혀 있어 영문 디스플레이 폰트를 **DejaVu Serif Condensed**로 대체해 검사했어요. 이 폰트는 실제 폰트(Instrument Serif)보다 넓어서, 넘침 검사는 실제보다 보수적으로 됐어요.
- 실제 폰트 폭은 사용자 브라우저에서 따로 측정했어요. "PUNCHNELLO"가 60px에서 294px로, 모바일 가용 폭 316px 안에 들어가요.
